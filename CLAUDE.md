## Repository Overview

This is the Lingaro Icons Catalog - a collection of 248 SVG icons organized into thematic categories. The icons use a consistent purple color theme (`#783cbe`) and are designed for use in presentations, dashboards, and corporate materials.

## Structure

```
icons/
  lingaro_set4/           # Main icon set
    Absract/              # Abstract/conceptual icons (brainstorm, puzzle, rocket, etc.)
    Arrows Icons/         # Navigation and directional icons
    Buildings/            # Corporate, warehouse, home icons
    Data Analysis Charts/ # AI, cloud, database, chart icons
    Documents/            # Document, award, certificate icons
    Globes/               # Network and planet icons
    Green Energy/         # Ecology, sustainability icons
    Hands/                # Hand gesture icons
    Health/               # Health, sports, wellness icons
    Logistic/             # Shipping, transportation icons
    Marketing/            # Marketing and communication icons
    Mobile phones/        # Device icons
    Money/                # Financial icons
    Monitors/             # Screen and display icons
    Personas/             # People and user icons
    Safety/               # Security and safety icons
    Social Media/         # Social platform icons
    Time/                 # Clock and calendar icons
```

## Icon Format

- All icons are SVG format with XML declaration
- ViewBox dimensions vary per icon (typically around 17-25 units)
- Single fill color using CSS class `.cls-1` with `fill: #783cbe` (Lingaro purple)
- Layer structure: `Layer_2` as root, `Layer_1-2` containing icon paths

## Working with Icons

To list all icons:
```bash
find icons -name "*.svg"
```

To count icons per category:
```bash
find icons -type d -exec sh -c 'echo -n "{}: "; find "{}" -maxdepth 1 -name "*.svg" | wc -l' \;
```

## API Server

The project includes a FastAPI-based REST API with semantic search capabilities.

### Running the API
```bash
# Install dependencies
pip install -r scripts/requirements.txt

# Set OpenAI key for semantic search (optional)
export OPENAI_API_KEY=your_key

# Run the server
python run_api.py
```

API available at http://localhost:8000 with docs at http://localhost:8000/docs

### Key Endpoints
- `GET /search?q={query}` - Semantic search for icons
- `GET /icons` - List all icons (paginated)
- `GET /icons/{id}` - Get icon by ID
- `GET /categories` - List categories
- `GET /tags` - List popular tags

### Project Structure
```

  js/search.js    # Client-side search for static site
```
